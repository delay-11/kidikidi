# Keycap Draft & Quote Tool

키캡 시안 제작 및 견적 요청을 위한 웹 기반 내부 툴.

옵션 선택, 이미지 업로드, 예상 금액 확인, 이메일 접수를 지원한다.

## Features

* 키캡 / 키링 옵션 선택
* 프로파일 및 규격 선택 (OEM / XDA / MAO)
* 이미지 업로드 및 요청사항 입력
* 예상 견적 실시간 계산
* EmailJS 기반 메일 전송
