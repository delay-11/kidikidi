# Keycap Draft Tool

키캡 시안 제작을 위한 웹 기반 툴입니다.
주문정보 입력 후 프로파일/규격을 선택하고,
이미지·배경·텍스트를 조합해 시안을 제작할 수 있습니다.  

---

## Access

🌐 https://custom.keycapdesign.co.kr/

---

## Features

* 주문정보 입력
* 프로파일 및 규격 선택 (OEM / XDA / MAO)
* 이미지 업로드 기반 시안 제작
* 단색 및 그라데이션 배경 설정
* 텍스트 추가 및 색상/정렬 설정
* 캔버스 기반 위치, 크기, 회전 조정
* 시안 리스트 관리 및 수량 조정
* 시안 확정 및 이메일 접수
