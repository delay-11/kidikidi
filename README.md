# 키캡 시안 제작 사이트 업데이트 기록

시안 제작 사이트의 주요 수정 및 개선 내역

---

## v1.0 초기 오픈 ~ 기본 기능 안정화

* 키캡 시안 제작을 위한 전용 사이트 개설
* 주문번호를 기준으로 시안 제작 페이지에 접속할 수 있도록 구성
* 이미지 업로드 후 캔버스에서 시안을 제작할 수 있도록 기본 기능 구성
* 제작한 시안을 목록에 추가한 뒤 최종 확정할 수 있도록 시안 추가 / 시안 확정 흐름 구성
* 사용자가 제작 방법을 확인할 수 있도록 제작 가이드 영상 연결
* 실제 사용 흐름에 맞춰 제작 가이드 영상 안내 내용 수정
* 시안 확정 시 접수 메일이 정상 전송되도록 메일 전송 오류 수정
* 레이저 옵션 선택 시 제작 조건에 맞게 전체 배경이 흰색으로 고정되도록 수정

---

## v1.5 제작 편의 기능 개선

* 캔버스 안에서 원하는 색상을 바로 추출할 수 있도록 색상 추출 기능 추가
* 웹 환경에서 먼저 캔버스 내 색상 추출 기능 적용
* 모바일에서도 캔버스 내 색상 추출이 가능하도록 기능 추가
* 제작 기준을 더 단순하게 확인할 수 있도록 가이드라인 표시 방식을 안전선 중심으로 정리
* 시안 제작 시 인쇄 가능 범위를 더 쉽게 확인할 수 있도록 안전선 표시 방식 개선
* 화면을 더 깔끔하게 정리하기 위해 프로파일 / 규격 설명 영역 숨김 처리
* 기존 툴팁 안내를 제거하고, 필요한 안내는 토스트 알림으로 표시되도록 변경

---

## v2.0 UI 개선 및 배경 기능 추가

* 전체 제작 화면 UI 개선
* 주문 정보 / 옵션 선택 / 캔버스 / 시안 목록 영역이 더 명확하게 보이도록 화면 구조 정리
* 사용자가 시안 제작 흐름을 더 쉽게 이해할 수 있도록 버튼, 안내 문구, 영역 배치 개선
* 인쇄 안전선 기준을 더 쉽게 확인할 수 있도록 인쇄 안전선 안내 추가
* 단색 배경뿐만 아니라 그라데이션 배경도 사용할 수 있도록 그라데이션 기능 추가
* 그라데이션 배경 적용 시 시안 썸네일이 올바르게 표시되지 않던 오류 수정

---

## v2.1 배경 설정 및 모바일 대응 개선

* 배경 설정 영역의 단색 / 그라데이션 전환 오류 수정
* 그라데이션 설정 항목을 시작 색상, 끝 색상, 방향, 경계 위치, 퍼짐 정도로 정리
* 경계 위치와 퍼짐 정도를 초기값으로 되돌릴 수 있는 초기화 기능 추가
* 단색 컬러피커를 직관적인 색상 보드 형태로 변경
* 컬러피커 터치 위치와 선택 표시 위치가 달라지던 문제 수정
* 모바일에서 배경 설정 영역이 화면 밖으로 밀리거나 잘리지 않도록 반응형 레이아웃 수정
* 모바일 캔버스 안내 문구가 겹치지 않도록 안내칩 표시 방식 개선
* 시안 제작 진입 시 인쇄 가이드 팝업이 정상적으로 표시되도록 수정
* 인쇄 가이드 팝업 크기를 화면에 맞게 조정
* 텍스트 색상 선택 버튼의 스타일 오류 수정

---

## v2.2 인쇄 가이드 및 배치 예시 안내 개선

* 시안 제작 전 확인하는 인쇄 가이드 팝업을 2단계 안내 방식으로 변경
* 기존 인쇄 안전선 안내에 더해 실제 시안 배치 예시 안내 이미지 추가
* 첫 번째 안내에서는 인쇄 안전선, 측면, 윗면, 키캡 색상 적용 범위를 확인할 수 있도록 구성
* 두 번째 안내에서는 측면 문구 위치, 배경 채우기, 중요 이미지 위치에 대한 실제 제작 예시를 확인할 수 있도록 구성
* 안내 내용을 모두 확인한 뒤에만 다시 보지 않기 버튼을 사용할 수 있도록 버튼 표시 방식 수정
* 인쇄 가이드 팝업에서 다음 / 이전 버튼으로 안내 이미지를 순서대로 확인할 수 있도록 기능 추가
* 다시 보지 않기 설정 후에도 인쇄 가이드 보기 버튼을 통해 수동으로 안내를 다시 확인할 수 있도록 구성
* 인쇄 가이드 팝업 관련 스크립트를 별도 JS 파일로 분리하여 관리하기 쉽도록 정리
* 인쇄 가이드 팝업이 정상적으로 표시되지 않던 로드 순서 문제 수정

---

## v2.3 Bootstrap 기반 UI 리뉴얼 및 단계형 제작 흐름 개선

* 기존 시안 제작 기능은 유지하면서 Bootstrap 기반 UI 구조로 화면 구성 정리
* 주문정보 입력 → 시안 제작 → 시안 확정 순서로 진행되는 단계형 제작 흐름 개선
* 사용자가 현재 진행 중인 단계를 쉽게 확인할 수 있도록 상단 단계 표시 UI 개선
* 단계 이동 시 현재 단계가 중심에 오도록 단계 표시 영역 정렬 방식 개선
* 주문 정보 입력 완료 후 안내 문구가 토스트 알림으로 표시되도록 변경
* 주문한 프로파일 / 규격을 선택하도록 안내 문구 정리
* 상단 주문번호 / 프로파일 / 규격 / 레이저 표시 영역을 더 간결한 텍스트형 UI로 변경
* 주문 옵션 선택 안내 영역의 박스 및 점선 스타일을 제거하여 화면을 더 깔끔하게 정리
* 시안 제작 화면의 이미지 / 배경 / 텍스트 도구 탭 UI 개선
* 시안 추가 버튼의 하단 고정 방식을 해제하여 화면 흐름에 맞게 표시되도록 수정
* 배경 설정 탭 전환 시 화면 좌우 폭이 줄어들어 보이던 문제 개선
* 텍스트 도구 영역의 레이아웃 정리

  * 텍스트 입력 / 폰트 타입 / 텍스트 색상 / 텍스트 정렬 영역 배치 개선
  * 텍스트 추가 / 삭제 버튼 정렬 개선
  * 폰트 타입 버튼을 3열 2행 구조로 정리
  * 폰트 타입 버튼이 실제 적용 폰트 기준으로 표시되도록 수정
  * 텍스트 입력 시 폰트 타입 버튼 라벨이 변경되지 않도록 수정
* 선택된 버튼의 불필요한 노란색 조명 / 포커스 효과 제거
* 모바일 화면에서 이전 / 현재 단계 / 다음 버튼이 한 줄로 표시되도록 개선
* 모바일에서도 단계 이동과 제작 화면이 자연스럽게 보이도록 반응형 스타일 보정
* 레이저 블랙 / 화이트 선택 시 배경이 흰색으로 고정된다는 토스트 알림이 표시되도록 유지
* 기존 캔버스 제작, 시안 리스트, 시안 확정, 메일 전송 로직은 유지

## 운영 안내

본 사이트는 키캡 시안 제작 및 접수를 위한 전용 제작 시스템입니다.

구매자는 주문 정보 입력 후 구매한 프로파일 / 규격 / 레이저 옵션을 선택하고, 이미지 업로드 또는 배경 / 텍스트 설정을 통해 시안을 제작할 수 있습니다.

시안 확정 후에는 제작이 진행될 수 있으므로, 주문 정보와 시안 내용을 반드시 확인한 뒤 확정해야 합니다.
