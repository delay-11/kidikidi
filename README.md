# Keycap Draft Tool

키캡 시안 제작을 위한 웹 기반 내부 툴.

주문 정보를 기반으로 시안을 제작하고 장바구니 관리 및 이메일 전송을 수행한다.

---

## Features

* 주문자 정보 입력
* 키캡 규격 선택 (OEM / XDA / MAO)
* 캔버스 기반 시안 편집
* 제작 가이드라인 표시
* 장바구니 관리
* 견적 요청 옵션
* EmailJS 기반 메일 전송
* 시안 파일 첨부 (10개 이상 ZIP)
