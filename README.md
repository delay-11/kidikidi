# Keycap Design Draft Tool

웹 기반 키캡 시안 제작 툴입니다.
주문 정보를 기반으로 키캡 시안을 제작하고 장바구니 관리, 견적 요청, 이메일 전송까지 하나의 페이지에서 처리할 수 있도록 제작되었습니다.

실제 키캡 제작 가이드라인을 기반으로 캔버스 편집 기능과 규격별 제작 가이드를 제공합니다.

---

# Preview

시안 제작 페이지

* 주문 정보 입력
* 키캡 규격 선택
* 캔버스 기반 디자인 편집
* 장바구니 관리
* 시안 확정 및 이메일 전송

---

# 주요 기능

## 주문 정보 입력

* 주문자명 입력
* 연락처 입력
* 주문번호 입력
* 이메일 입력
* 주문번호 URL 자동 입력 지원
* 이미 확정된 주문번호 잠금 처리

---

## 시안 제작 기능

캔버스 기반 디자인 편집 기능을 제공합니다.

지원 기능

* 이미지 업로드
* 드래그 이동
* 크기 조절
* 회전
* 배경 색상 변경

편집 UI

* 모서리 핸들 : 크기 조절
* 상단 핸들 : 회전
* 드래그 : 이동
* Alt + 드래그 : 중심 확대

---

## 키캡 규격 지원

지원 프로파일

* OEM
* XDA
* MAO

각 프로파일에 맞는 캔버스 사이즈와 제작 가이드라인이 자동 적용됩니다.

---

## 가이드라인 시스템

캔버스에는 제작 가이드라인이 표시됩니다.

빨간선
→ 실제 키캡 외곽

노란선
→ 인쇄 안전 영역

가이드 방식

OEM / XDA
→ 수치 기반 가이드라인

MAO
→ SVG 기반 가이드라인

---

## 장바구니 시스템

여러 개의 시안을 저장하고 관리할 수 있습니다.

지원 기능

* 시안 추가
* 시안 선택
* 수량 변경
* 시안 삭제
* 자동 가격 계산
* 총액 계산

---

## 가격 계산

가격은 다음 기준으로 계산됩니다.

* 프로파일
* 키캡 규격
* 레이저 각인 옵션
* 수량

추가 적용

수량 할인

```
500개 이상
1000개 이상
5000개 이상
```

제작 일정 할증

```
10일 제작 : +20%
5일 제작 : +30%
```

---

## 견적서 요청 기능

견적서 요청 옵션을 활성화하면 추가 정보를 입력할 수 있습니다.

입력 항목

* 제작 일정 선택
* 희망 납기일
* 사업자등록증 업로드

추가 옵션

키캡 키링

* 수량
* LED 여부
* 색상
* 키링 타입

포장 옵션

* 개별 OPP 포장
* 시안별 묶음 포장
* 세트 포장
* 케이스 제작

추가 옵션

* 대지 포함
* 스티커 제작

기타 요청사항 입력 가능

---

## 이메일 전송

시안 확정 시 이메일이 자동 발송됩니다.

전송 방식

EmailJS 사용

전송 대상

* 회사 메일 (시안 접수)
* 고객 메일 (견적서)

첨부 파일

* 시안 이미지 자동 첨부
* 시안 10개 이상일 경우 ZIP 압축 첨부
