## v3.4.4 캔버스 초기화 + 배경은 직접 설정해야 적용 + 빈 곳 안내 문구

### 이미지
* [업로드] [삭제] 옆에 [초기화] 추가: 이미지 · 텍스트 · 배경을 모두 비워 체크무늬 빈 캔버스로 (5초 동안 [되돌리기], 모바일은 지우개 아이콘)
* 크기 줄의 [초기화] → [설정 초기화] (크기 · 회전을 처음 상태로)
* PC: 복제한 시안이라 [교체]가 보이면 이미지 버튼 줄을 4칸으로

### 배경
* [단색] / [그라데이션] 버튼은 모드만 바꾸고 배경은 비워 둠 — 색 · 스포이드 · 방향 · 경계 위치 · 퍼짐 정도를 직접 바꿀 때 적용
* 배경을 안 정했으면 색 칸은 체크무늬, 색상 코드는 비움("색상 선택"), 그라데이션 색은 "선택"으로 표시
* 그라데이션 [초기화] → [설정 초기화] (배경을 안 정했을 땐 값만 되돌림)
* 그라데이션 시작 / 끝 색상 버튼의 글씨("선택", 색상 코드)를 고정폭 글꼴 대신 사이트 기본 글꼴로

### 빈 곳 안내
* 캔버스 아래 빨간 안내 문구 삭제
* [시안 추가] 알림 문구 변경: 캔버스 전체 영역을 빈틈없이 채워 주세요. / 배경 탭에서 색상을 선택하거나 스포이드로 지정할 수 있습니다. / 목업 기준으로만 채울 경우, 제품 측면에 배경이 적용되지 않을 수 있습니다.

## v3.4.3 배경이 저절로 흰색으로 정해지던 문제 수정 + 배포 후 새 파일 받기

* 주문정보 입력 후 프로파일만 골라도 배경이 흰색(#ffffff)으로 저절로 정해지던 문제 수정 — 색상 선택기(Pickr)가 화면 색 맞추기에도 "색 바뀜" 신호를 보내 사용자가 고른 것처럼 처리됐음. 이 때문에 체크무늬가 안 보이고 빈 캔버스로도 시안 추가가 됐음
* 배경 탭의 [단색] / [배경 색상] 버튼만 눌러도 흰 배경이 정해지던 문제 수정 — 실제로 색을 고를 때(컬러보드 · 색상 코드 · 스포이드 · 그라데이션)만 배경이 정해짐
* CSS / JS 주소 끝에 ?v=버전 을 붙여, 배포 후에도 브라우저가 예전 파일을 쓰지 않게 함 (버전 올릴 때 같이 변경)
* 이미 흰 배경이 들어간 채 저장된 시안은 그대로 유지

## v3.4.1 캔버스 빈 곳 체크무늬 + 빈 곳 있으면 시안 추가 막기

### 캔버스 꽉 채우기
* 배경을 안 정하면 편집 캔버스의 빈 곳을 체크무늬(투명)로 표시 — 화면에만 보이고 접수 이미지 · 썸네일은 흰색 그대로
* [시안 추가] / [시안 수정 완료]는 배경색을 정했거나(흰색도 가능) 이미지가 캔버스를 꽉 덮었을 때만 가능. 빈 곳이 있으면 안내 알림 + 캔버스 아래 안내 ([배경] 또는 [캔버스 채우기])
* 투명 PNG의 투명한 부분도 빈 곳으로 봄 (실제로 하얗게 찍힘). 레이저(흰색 고정) 시안은 옆면 인쇄가 없어 예외
* 이미 시안 리스트에 저장된 예전 시안은 막지 않음

## v3.3.0 화면 다듬기 + 키보드 · 화면낭독기 지원 + 안 쓰는 코드 정리

### MOA 프로파일 열기
* 프로파일 목록의 "MOA (준비중)"을 "MOA"로 바꿔 선택 가능하게 (주문정보 화면 · PC 빠른 변경 팝업). 규격은 MOA 하나, 레이저 옵션 없음
* 주문 옵션 안내 문구에 MOA 추가: 프로파일(OEM / XDA / MAO / MOA)
* 가이드선 · 목업: 몸통 180(XDA와 같음) / 윗면 140 / 안전선 125(윗면 안쪽 7.5px), 셋 다 모서리가 크게 둥근 네모

### 주문정보 화면 (1단계)
* 배경 왼쪽 위 노란 빛 번짐 · 큰 카드 그림자를 없애고 단색 배경 + 테두리로 정리
* 처음엔 "- / - /"만 보이던 위쪽 주문 정보 줄을 1단계에서는 숨김 (2단계부터 입력한 값과 함께 보임)
* 누를 수 없는 [이전] 버튼을 1단계에서 빼고, 제목을 카드 왼쪽 끝에 맞춤
* 아직 못 누를 때 흐릿하던 노란 [다음]을 읽히는 회색으로 (다 입력하면 노란색)
* 모바일: 프로파일 / 규격 / 레이저 칸이 "선택…"처럼 잘리던 것을 2칸 + 아래 1칸으로
* 버전 표시를 알약 모양 대신 작은 글씨로, 푸터 "All rights reserved." 삭제

### 시안 제작 · 확정 화면 (2 · 3단계)
* 큰 카드 안에 카드가 또 들어 있던 겹 구조를 한 겹 줄임 (모바일은 캔버스가 더 넓어짐)
* "프로파일/규격", "캔버스", "배경", "시안 리스트" 회색 알약 라벨 → 작은 글씨
* 프로파일/규격 변경 버튼: 노란 동그라미 ▼ 대신 테두리 + 화살표가 있는 선택 칸 모양
* 시안 카드: 배경이 없을 때 생기던 "-" 빈 줄 삭제, 수량 [-] [1] [+] [x] 높이 통일
* 비활성 버튼(시안 추가, 삭제, 배경 도구 등)을 흐리게 지우지 않고 읽히는 회색으로 통일
* 이미지 탭 "PNG / JPG / WEBP 가능", 텍스트 개수 0/3, 인쇄 가이드 "시안 배치 / 목업" 노란 칩 → 작은 글씨 · 회색 표시
* 그라데이션 "경계 위치 / 퍼짐 정도" 상자 안의 상자 정리, 시안 최종 확정 팝업의 "안내" 칩 삭제
* 모바일 꾸미기 메뉴: 노란 타일 3개 → 회색 타일 (노란색은 [꾸미기] 버튼에만)
* 모바일: 위쪽 주문 정보 줄 한 줄로, 스크롤할 때 "이전 | 시안 제작 | 다음" 줄 위로 내용이 비치던 문제 수정 (로고 줄도 위에 고정)

### 키보드 · 화면낭독기 · 사용성
* 시안 삭제(x) 후 5초 동안 [되돌리기] 버튼 (실수로 지워도 같은 자리로 복구)
* 입력칸 라벨 연결: "주문자명 *" 등을 누르면 입력칸으로 커서 이동
* 팝업 3개(프로파일/규격, 시안 확정, 인쇄 가이드): 열면 팝업 안으로 포커스 이동, Esc로 닫기, 닫으면 원래 버튼으로 복귀 (시안 접수 중에는 안 닫힘)
* 키보드 포커스 테두리 (마우스 클릭 땐 안 보임), 그라데이션 슬라이더 포커스 표시 복구
* 본문 바로가기(Tab을 눌렀을 때만 보임), 화살표 버튼 이름, 캔버스 안내 문구 읽어주기
* 전화번호 칸 숫자 키패드, 이름 · 전화 · 이메일 자동완성
* 시스템 "동작 줄이기" 설정을 켠 사용자는 애니메이션 없이

### 코드 정리
* 파일마다 직접 적혀 있던 색 336곳을 base.css의 색 이름(토큰)으로 묶음 (보이는 색은 그대로)
* 안 쓰는 CSS 규칙 76개 · "미사용 확인" 주석 블록 · 안 쓰는 JS 함수 삭제 (약 680줄)
* 안 쓰는 가이드 영상(files/guide_video.mp4, 약 10MB) · SNS 아이콘 삭제

## v3.2.0 시안 복제 · 이미지 교체 + 시안 추가 버튼 위치 + MOA 준비중

### 시안 복제 · 이미지 교체
* 시안 리스트 카드에 [복제] 추가: 이미지 배치 · 위치 · 크기 · 배경 · 텍스트를 그대로 복사해 원본 바로 아래에 넣고, 복사본을 바로 편집 화면에 불러옴
* 이미지 도구에 [교체] 추가: 선택한 이미지를 같은 위치 · 회전 · 레이어 · 크기(%) 그대로 새 파일로 바꿈 (비율이 같은 이미지면 완전히 같은 크기). 복제한 시안을 편집할 때만 보임
* 버튼 문구 정리: 카드 [시안 수정] → [수정], 이미지 도구 [이미지 업로드] / [이미지 교체] → [업로드] / [교체]

### 시안 제작 화면
* PC: [시안 추가] / [시안 수정 완료] 버튼을 오른쪽 시안 리스트 맨 위로 (예전엔 왼쪽 맨 아래라 스크롤해야 보였음). 모바일은 아래 고정 바 그대로
* 이미지가 캔버스 위쪽 끝까지 오면 회전 / 삭제 버튼이 캔버스 위 안내 문구에 가려지던 문제 수정 (버튼이 항상 캔버스 안에 보이도록)
* 모바일 이미지 시트: 업로드 · 삭제 · 교체 아이콘 옆 안내 칩 두 개를 위아래로 쌓아 오른쪽 정렬 (320px 폭까지 한 줄)
* 시안 카드 버튼 줄이 PC 오른쪽 패널 밖으로 넘치지 않게 정리

### MOA (준비중)
* 프로파일 목록에 "MOA (준비중)" 추가 — 보이기만 하고 선택은 안 됨
* 가이드선 · 목업 미리 준비: 몸통은 XDA와 같은 180, 윗면 140 · 안전선 120. 셋 다 모서리가 크게 둥근 네모, 목업 옆면 음영은 옅고 부드럽게 (도면이 나오면 constants.js 숫자만 바꾸면 됨)

## v3.0.1 캔버스 채우기 안내 강조 + 이미지 크기 % 조절

### 시안 제작 화면
* 기본 화면을 목업 → 가이드선으로 변경. 목업은 정보줄의 "목업 / 가이드선"을 눌러야 보임 (목업 모양 안만 채우고 캔버스를 다 채우지 않은 시안 접수 방지). 예전 기본값(목업)이 저장된 사용자도 가이드선부터 시작
* 캔버스 안내 칩("배경은 빈 공간 없이 채우기" / "실제 제작 시 CMYK 기준")을 없애고 "목업 표시 영역이 아닌, 캔버스 전체를 채워주세요." 안내를 빨간색으로 강조
* 캔버스 안내 문구는 캔버스를 가리지 않도록 캔버스 위쪽 바깥에 표시 (PC는 한 줄, 모바일은 두 줄)
* 인쇄 안전선: XDA와 프로파일 선택 전 기본 화면의 안전선을 윗면보다 안쪽(130×130)으로 조정
* PC 정보줄의 프로파일/규격 글자(예: "OEM / R4-1U")가 위로 붙어 보이던 문제 수정 (칩 · ▼ 버튼과 같은 높이로 가운데 정렬)

### 이미지 크기 % 조절
* 손으로 늘리고 줄이면 여러 시안을 같은 크기 · 비율로 맞추기 어려워서, 이미지를 올리면 크기(%) 입력칸과 [캔버스 채우기] 표시
* 100% = 비율 그대로 캔버스를 꽉 채우는 크기 → 여러 시안을 같은 %로 맞출 수 있음. 크기를 바꿔도 비율 · 위치는 유지, 손으로 늘리면 %도 따라 바뀜
* [캔버스 채우기]: 100%로 키우고 회전을 풀어 가운데 배치
* 크기(%) 칸에 숫자를 입력할 때 생기던 외곽선 · 노란 테두리 제거
* PC: 안내사항 자리에 "크기" 제목 → 크기 · 캔버스 채우기 → PNG / 투명 배경 안내 칩 순서

* 새로 올린 이미지는 기존처럼 텍스트 아래에 들어가서 이미 입력한 텍스트를 가리지 않음

* 배치가 1통뿐인 일반적인 주문은 기존과 동일하게 병렬로 빠르게 처리되어 접수 속도 영향 없음
