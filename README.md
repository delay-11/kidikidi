# 키캡 시안 제작 사이트 업데이트 기록

시안 제작 사이트의 주요 수정 및 개선 내역을 정리한 기록입니다.  
정확한 날짜보다는 큰 업데이트 흐름 기준으로 정리했습니다.

---

## v1.0 초기 오픈 ~ 기본 기능 안정화

- 키캡 시안 제작을 위한 전용 사이트 개설
- 주문번호를 기준으로 시안 제작 페이지에 접속할 수 있도록 구성
- 이미지 업로드 후 캔버스에서 시안을 제작할 수 있도록 기본 기능 구성
- 제작한 시안을 목록에 추가한 뒤 최종 확정할 수 있도록 시안 추가 / 시안 확정 흐름 구성
- 사용자가 제작 방법을 확인할 수 있도록 제작 가이드 영상 연결
- 실제 사용 흐름에 맞춰 제작 가이드 영상 안내 내용 수정
- 시안 확정 시 접수 메일이 정상 전송되도록 메일 전송 오류 수정
- 레이저 옵션 선택 시 제작 조건에 맞게 전체 배경이 흰색으로 고정되도록 수정

---

## v1.5 제작 편의 기능 개선

- 캔버스 안에서 원하는 색상을 바로 추출할 수 있도록 색상 추출 기능 추가
- 웹 환경에서 먼저 캔버스 내 색상 추출 기능 적용
- 모바일에서도 캔버스 내 색상 추출이 가능하도록 기능 추가
- 제작 기준을 더 단순하게 확인할 수 있도록 가이드라인 표시 방식을 안전선 중심으로 정리
- 시안 제작 시 인쇄 가능 범위를 더 쉽게 확인할 수 있도록 안전선 표시 방식 개선
- 화면을 더 깔끔하게 정리하기 위해 프로파일 / 규격 설명 영역 숨김 처리
- 기존 툴팁 안내를 제거하고, 필요한 안내는 토스트 알림으로 표시되도록 변경

---

## v2.0 UI 개선 및 배경 기능 추가

- 전체 제작 화면 UI 개선
- 주문 정보 / 옵션 선택 / 캔버스 / 시안 목록 영역이 더 명확하게 보이도록 화면 구조 정리
- 사용자가 시안 제작 흐름을 더 쉽게 이해할 수 있도록 버튼, 안내 문구, 영역 배치 개선
- 인쇄 안전선 기준을 더 쉽게 확인할 수 있도록 인쇄 안전선 안내 추가
- 단색 배경뿐만 아니라 그라데이션 배경도 사용할 수 있도록 그라데이션 기능 추가
- 그라데이션 배경 적용 시 시안 썸네일이 올바르게 표시되지 않던 오류 수정
